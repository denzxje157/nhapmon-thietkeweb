/* Công thức then chốt của hiệu ứng lật thẻ 3D */
.flip-card {
  perspective: 1000px; /* Thiết lập phối cảnh 3D */
}
.flip-card-inner {
  transform-style: preserve-3d; /* Giữ cấu trúc 3D cho thẻ con */
  transition: transform 0.8s cubic-bezier(0.34, 1.56, 0.64, 1);
}
.flip-card:hover .flip-card-inner {
  transform: rotateY(180deg); /* Xoay 180 độ quanh trục thẳng đứng Y */
}
.flip-card-front, .flip-card-back {
  backface-visibility: hidden; /* Ẩn mặt úp lưng để không bị xuyên thấu */
}

Gợi ý Prompt & Tư duy Kỹ thuật LHU

🎯 Prompt đã sử dụng: "Tạo hiệu ứng lật thẻ (Card Flip) bằng CSS thuần cho hồ sơ nhân sự của Nguyễn Hoàng Anh. Cấu trúc gồm container chính và hai thẻ con .card-front, .card-back. Khi hover vào thẻ, nó sẽ xoay 180 độ theo trục Y để hiện mặt sau. Sử dụng transform-style: preserve-3d và backface-visibility: hidden. Đảm bảo hiệu ứng có chiều sâu 3D mượt mà và hoạt động tốt trên cả điện thoại (chạm để lật)."
