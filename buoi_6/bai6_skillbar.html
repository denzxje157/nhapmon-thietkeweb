Skill Bar Animation (Thanh kỹ năng tự động)

Khi tải trang web, các thanh tiến độ sẽ tự động tăng dần từ 0% đến giá trị phần trăm đích với đường cong gia tốc mượt mà và giữ nguyên trạng thái kết quả.

/* CSS Keyframes cho thanh tiến trình nạp tự động */
.skill-progress-fill {
  height: 100%;
  width: 0; /* Khởi đầu ở 0% */
  border-radius: 9999px;
  background: linear-gradient(90deg, #3b82f6, #06b6d4);
  /* Chạy từ 0 đến biến --target-width, giữ nguyên ở điểm kết thúc */
  animation: fillProgressAnim 1.8s cubic-bezier(0.22, 1, 0.36, 1) forwards;
}

.skill-progress-fill.html { 
  --target-width: 95%; 
  animation-delay: 0.1s; 
}

@keyframes fillProgressAnim {
  0% {
    width: 0;
  }
  100% {
    width: var(--target-width); /* Giữ lại đúng mức phần trăm */
  }
}

Gợi ý Prompt & Tư duy Kỹ thuật LHU

🎯 Prompt đã sử dụng: "Viết CSS cho các thanh tiến trình (Progress bars) hiển thị kỹ năng lập trình web. Khi trang được tải, các thanh này sẽ tự động chạy từ 0% đến mức phần trăm cụ thể (ví dụ 95%, 90%, 85%) trong vòng 1.8 giây với hiệu ứng chuyển động mượt mà. Sử dụng thuộc tính animation-fill-mode: forwards để cố định thanh sau khi chạy xong."

💡 Tinh chỉnh animation-fill-mode: forwards: Mặc định sau khi chạy hết keyframes, CSS sẽ đưa phần tử trở về trạng thái CSS tĩnh ban đầu (`width: 0`). Nhờ có thuộc tính `forwards`, thanh tiến trình được "khóa" lại chính xác ở mốc giá trị cuối cùng.
