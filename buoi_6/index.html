02 Tuần 2

Tư duy Semantic HTML5 & Cấu trúc Web Hệ thống

Nội dung: Làm chủ tư duy "No Div" bừa bãi, áp dụng 7+ thẻ Semantic tiêu chuẩn (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>) để tối ưu hóa SEO và cấu trúc cây DOM.
• Hoạt động 1: X-Ray Vision soi cấu trúc Web DOM tree.
• Hoạt động 2: Trang Portfolio cá nhân Semantic với thanh điều hướng HA, thẻ Aside thông tin sinh viên LHU và lưới kỹ năng.

03 Tuần 3

CSS Layout System (Flexbox & CSS Grid)

Nội dung: Phân biệt rõ nét Flexbox (dàn trang 1 chiều linh hoạt cho Menu, Card components) và CSS Grid (hệ thống lưới 2 chiều cho toàn bộ bố cục website). Nắm vững mô hình Box Model, sử dụng thuộc tính gap hiện đại thay cho margin thủ công.
• Hoạt động 1: "Flex & Grid Battle" – Thử thách căn giữa đối tượng tức thì và lưới 3 cột tự co giãn.
• Hoạt động 2: Xây dựng bố cục Portfolio với Sidebar 250px và Main content 75% bằng grid-template-areas.

04 Tuần 4

Design System & Tư duy Responsive (Mobile First)

Nội dung: Xây dựng hệ thống biến CSS Tokens tại :root (màu sắc, spacing scale, radius). Áp dụng chủ đề **Shonen Anime Action** cực cháy (One Piece, Naruto, Jujutsu Kaisen, Demon Slayer) qua 4 hoạt động:
• HĐ 1: Bảng mã màu thông minh & Chế độ Sáng/Tối (Dark/Light Mode).
• HĐ 2: Responsive Portfolio co giãn 1 cột trên Mobile (< 768px).
• HĐ 3: Breakpoint Challenge (Desktop 4 cột, Tablet 2 cột, Mobile 1 cột).
• HĐ 4: Design System Refactoring loại bỏ 100% hardcode pixel.

05 Tuần 5

Hiệu ứng Chuyển động & Thư viện Hiệu ứng (CSS Animations)

Nội dung: Hiểu rõ nguyên lý chuyển động trong Web (Timing functions, Keyframes, 2D/3D Transforms, Transition).
• HĐ 1: Micro-interactions nút bấm cảm xúc phản hồi đàn hồi với hàm cubic-bezier.
• HĐ 2: "Loading Master" – Màn hình Preloader Spinner xoay 360 độ vô hạn @keyframes spin.
• HĐ 3: "AOS - Scroll Reveal" – Tích hợp thư viện AOS qua CDN để xuất hiện mượt mà khi cuộn trang.
• HĐ 4: Refactoring Performance – Thay đổi thuộc tính từ top/left sang GPU transform: translate cam kết 60 FPS.
