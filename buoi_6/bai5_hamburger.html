Modern Hamburger Menu (Biến đổi dấu X)

Chuyển đổi mượt mà biểu tượng ba gạch ngang truyền thống thành dấu "X" đóng mở thông qua CSS Transitions, Transform và Opacity.

Trình tương tác Hamburger & Menu Drawer

Bấm vào nút bên dưới để quan sát hoạt ảnh biến đổi: Thanh trên xoay 45°, thanh giữa mờ dần về 0, và thanh dưới xoay -45°.

/* Công thức biến đổi Hamburger sang dấu X */
.hamburger-line {
  width: 26px;
  height: 3px;
  background-color: #f8fafc;
  transition: transform 0.4s cubic-bezier(0.68, -0.6, 0.32, 1.6), opacity 0.3s ease;
  transform-origin: center;
}

/* Khi active */
.hamburger-btn.active .hamburger-line:nth-child(1) {
  transform: translateY(9px) rotate(45deg);   /* Dịch xuống tâm và xoay chéo */
  background-color: #ef4444;
}
.hamburger-btn.active .hamburger-line:nth-child(2) {
  opacity: 0;                                 /* Biến mất thanh giữa */
  transform: scaleX(0);
}
.hamburger-btn.active .hamburger-line:nth-child(3) {
  transform: translateY(-9px) rotate(-45deg); /* Dịch lên tâm và xoay ngược */
  background-color: #ef4444;
}
