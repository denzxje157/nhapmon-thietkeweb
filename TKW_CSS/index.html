Tối Ưu Giao Diện: Flexbox, CSS Grid & Hiệu Ứng Hover

Trải nghiệm trực quan các bài tập bố cục CSS hiện đại, căn giữa toàn màn hình 100vh, hệ thống lưới CSS Grid 3 cột và tương tác :hover đổi màu hình cái bia.

🎯 Tương Tác Hover Rê chuột vào cái bia để thử

Hiệu Ứng Hình Cái Bia: Chưa Chạm Màu Đỏ – Rê Chuột Màu Xanh Lá Cây

Yêu cầu: "Khi di chuyển chuột vào hình cái bia sẽ hiện màu xanh lá cây, còn không chạm vào là màu đỏ."

👇 Di chuyển chuột lên hình cái bia bên dưới

Không chạm: Màu Đỏ
➜
Rê chuột vào (:hover): Màu Xanh Lá
CSS Code (Hiệu ứng Hover Cái Bia) 
/* 1. Trạng thái bình thường (không chạm chuột): MÀU ĐỎ */
.ring-colored {
    fill: #ef4444;                 /* Màu đỏ */
    transition: fill 0.3s ease;    /* Chuyển màu mượt mà */
}

/* 2. Khi di chuyển chuột vào (:hover): MÀU XANH LÁ CÂY */
.bullseye:hover .ring-colored {
    fill: #22c55e;                 /* Đổi sang màu xanh lá cây */
}

/* Tùy chọn: Thêm hiệu ứng phóng to nhẹ khi hover */
.bullseye:hover {
    transform: scale(1.08);
    filter: drop-shadow(0 10px 20px rgba(34, 197, 94, 0.4));
}
📦 CSS Flexbox height: 100vh

Căn Giữa Thẻ '.container' Toàn Màn Hình Cả Chiều Dọc & Chiều Ngang

Yêu cầu: "Hãy viết mã CSS sử dụng Flexbox để căn giữa một thẻ có class là 'container' vào chính giữa trang web theo cả chiều dọc và chiều ngang. Đảm bảo 'container' có chiều cao toàn màn hình (100vh)."

Mô phỏng Viewport (100vh) - .container
🎯 Căn Giữa Hoàn Hảo

Nội Dung Nằm Chính Giữa Màn Hình

Phần tử được canh giữa đồng thời theo cả trục ngang (X) và trục dọc (Y).

display: flex; justify-content: center; align-items: center; height: 100vh;
CSS Code (Flexbox Căn Giữa 100vh) 
/* Mã CSS căn giữa toàn màn hình bằng Flexbox */
.container {
    display: flex;             /* Kích hoạt Flexbox */
    justify-content: center;   /* Căn giữa theo chiều ngang (trục chính) */
    align-items: center;       /* Căn giữa theo chiều dọc (trục phụ) */
    height: 100vh;             /* Chiều cao 100% chiều cao màn hình */
    width: 100%;               /* Chiều rộng toàn màn hình */
}
📐 CSS Grid gap: 20px | border-radius: 10px

Bố Cục Lưới 3 Cột Bằng Nhau, Khoảng Cách 20px, Bo Góc 10px

Yêu cầu: "Tạo một bố cục lưới (CSS Grid) gồm 3 cột bằng nhau, khoảng cách giữa các cột là 20px. Mỗi cột chứa một thẻ có màu nền xám nhạt và bo góc 10px."

01 🚀

Cột Số 1

Kích thước 1fr chia đều 1/3 chiều rộng lưới. Bo góc 10px tinh tế.

background: #f0f0f0
02 💎

Cột Số 2

Khoảng cách giữa các cột được thiết lập chính xác là 20px bằng thuộc tính gap.

gap: 20px
03 ⚡

Cột Số 3

Màu nền xám nhạt dịu mắt, tương thích hoàn hảo trên các kích cỡ màn hình.

border-radius: 10px
CSS Code (CSS Grid 3 Cột) 
/* Bố cục lưới CSS Grid 3 cột bằng nhau */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);  /* 3 cột độ rộng bằng nhau */
    gap: 20px;                              /* Khoảng cách giữa các cột là 20px */
}

/* Mỗi thẻ: nền xám nhạt và bo góc 10px */
.grid-item {
    background-color: #f0f0f0;             /* Màu nền xám nhạt */
    border-radius: 10px;                   /* Bo góc 10px */
    padding: 24px;
}
