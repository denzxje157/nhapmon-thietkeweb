Parallax Background (Hiệu ứng Chiều sâu)

Sử dụng thuộc tính nền cố định trong CSS thuần để tạo cảm giác ảnh nền nằm ở một tầng không gian sâu hơn, di chuyển với vận tốc khác khi người xem cuộn trang.

🌟 Cơ chế hoạt động của kỹ thuật CSS Fixed Background

Khi sử dụng thuộc tính background-attachment: fixed;, khung nhìn (Viewport) của trình duyệt sẽ đóng vai trò là cửa sổ nhìn thẳng vào bức ảnh nền được ghim cố định với màn hình. Các phần tử HTML khác nằm ở tầng trên (Z-index cao hơn) sẽ lướt qua bề mặt bức ảnh.

Kỹ thuật này mang lại vẻ đẹp điện ảnh (Cinematic) mà không tiêu tốn tài nguyên xử lý JavaScript scroll listener phức tạp, từ đó tối ưu hóa chỉ số FPS khi cuộn màn hình.

Mã nguồn CSS & Giải trình kỹ thuật

/* Bộ quy tắc then chốt để kích hoạt Parallax đơn giản */
.parallax-section {
  background-image: url('assets/hero-bg.jpg');
  background-attachment: fixed;  /* Ghim ảnh nền cố định vào Viewport */
  background-position: center;   /* Căn giữa tâm điểm bức ảnh */
  background-repeat: no-repeat;
  background-size: cover;        /* Phủ kín toàn bộ vùng chứa */
  min-height: 400px;
}

/* Lưu ý Responsive trên Mobile:
   Một số trình duyệt di động (iOS Safari) tối ưu tiết kiệm pin bằng cách tắt
   background-attachment: fixed. Khi cần thiết có thể fallback sang scroll: */
@media (max-width: 768px) {
  .parallax-section {
    background-attachment: scroll;
  }
}
