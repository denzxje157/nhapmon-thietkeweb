Pure CSS Typing Effect (Máy đánh chữ)

Mô phỏng chuyển động từng ký tự xuất hiện tuần tự kèm con trỏ nhấp nháy ở cuối dòng, ứng dụng 100% bằng CSS Animation thuần (không dùng bất kỳ dòng JavaScript nào).

Demo 1: Terminal Console Gõ Tự Động

Hoạt ảnh máy đánh chữ đang chạy liên tục: gõ chữ từng bước bằng hàm steps(), dừng lại để người đọc quan sát, sau đó xóa lùi và lặp lại chu kỳ.

/* Bộ Animation CSS thuần cho hiệu ứng máy đánh chữ */
.hero-typing-text {
  font-family: 'Fira Code', monospace;
  white-space: nowrap;        /* Giữ toàn bộ chữ trên 1 hàng ngang */
  overflow: hidden;            /* Cắt ẩn phần chữ chưa được gõ */
  border-right: 3px solid #0052cc; /* Con trỏ nhấp nháy */
  width: 0;                    /* Bắt đầu tại 0 ký tự */
  /* Chạy hiệu ứng gõ từng bước và nhấp nháy con trỏ */
  animation: 
    typingHeroSentence 4s steps(25, end) infinite,
    cursorBlink 0.75s step-end infinite;
}

@keyframes typingHeroSentence {
  0%, 10% { width: 0; }        /* Tạm dừng 0.4s lúc chưa gõ */
  45%, 75% { width: 100%; }    /* Đã gõ xong 100%, dừng lại 1.2s để đọc */
  90%, 100% { width: 0; }      /* Xóa lùi chữ và lặp lại chu kỳ mới */
}

@keyframes cursorBlink {
  0%, 100% { border-color: transparent; }
  50% { border-color: #0052cc; }
}

Gợi ý Prompt & Tư duy Kỹ thuật LHU

🎯 Prompt chuẩn theo giáo trình: "Hãy viết mã CSS tạo hiệu ứng máy đánh chữ (Typing effect) cho một thẻ tiêu đề Header: 'Tôi là Kỹ sư Phần mềm LHU'. Chữ sẽ xuất hiện dần dần từ trái sang phải bằng animation thay đổi width với hàm steps(25), kèm theo con trỏ nhấp nháy ở cuối dòng chữ. Dừng lại 1.5s cho người đọc rồi xóa lùi và lặp lại. Không sử dụng JavaScript."

💡 Tinh chỉnh kỹ thuật: Bằng cách chia giai đoạn keyframes thành 0% -> 45% (Gõ), 45% -> 75% (Dừng đọc), và 75% -> 90% (Xóa), người dùng có trải nghiệm thị giác chân thực và không bị mỏi mắt như các chuyển động giật cục đơn thuần.
