02

Quy tắc Media Query (< 768px)

Kiểm tra thay đổi bố cục linh hoạt bằng DevTools (F12)

🖥️

Desktop (≥ 768px)

Sử dụng CSS Grid 2 cột: grid-template-columns: 290px 1fr

  • Sidebar cố định độ rộng 290px bên trái
  • Thẻ phim Anime hiển thị dạng lưới 3 cột hiện đại
  • Project cards hiển thị 2 cột song song
📱

Mobile (< 768px)

Media query: @media (max-width: 767.98px)

  • Chuyển toàn bộ bố cục sang 1 cột duy nhất (1fr)
  • Sidebar nằm trên, Main content nằm dưới theo thứ tự đọc tự nhiên
  • Thẻ Anime và Project tự động xếp chồng 1 cột mượt mà
