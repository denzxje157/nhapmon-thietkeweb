Hiệu Ứng Hover Cái Bia

Di chuyển chuột vào hình cái bia bên dưới:

Không chạm: Màu Đỏ ➜ Rê chuột vào: Màu Xanh Lá 
/* 1. Bình thường (không chạm vào): MÀU ĐỎ */
.color-ring {
    fill: #ef4444; /* Màu đỏ */
    transition: fill 0.3s ease;
}

/* 2. Khi di chuyển chuột vào (:hover): MÀU XANH LÁ CÂY */
.target:hover .color-ring {
    fill: #22c55e; /* Màu xanh lá cây */
}
