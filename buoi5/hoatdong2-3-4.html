Hoạt động 4 (15 phút)

⚡ Refactoring Performance: Từ Top/Left sang Transform

Bí quyết sống còn để animation không bị giật lag (jank / stutter) trên trình duyệt di động: đưa chuyển động lên phần cứng GPU và loại bỏ hoàn toàn Layout Reflow.

❌ Chưa Tối Ưu (Legacy)

Sử dụng top / left

Thay đổi vị trí phần tử bằng top, left, margin-top bắt buộc CPU phải tính toán lại hình học trang (Layout / Reflow) và vẽ lại từng pixel (Repaint) trong mỗi khung hình. 

/* ❌ RẤT CHẬM - GÂY DROP FRAME */
@keyframes badFloating {
  0%   { top: 0px; left: 0px; }
  50%  { top: -20px; left: 10px; }
  100% { top: 0px; left: 0px; }
}
  • ⚠️ Bước 1: Layout (Reflow) — Rất nặng!
  • ⚠️ Bước 2: Paint (Repaint) — Tốn CPU!
  • ⚠️ Bước 3: Composite
  • 📉 Hậu quả: Tụt còn 15–25 FPS trên smartphone.
✅ Đã Refactor (Chuẩn 60 FPS)

Sử dụng transform: translate

Thuộc tính transform được chuyển thẳng sang GPU (Card đồ họa) xử lý độc lập tại tầng Composite. Hoàn toàn không làm ảnh hưởng đến cấu trúc trang web. 

/* ✅ SIÊU MƯỢT - KHÔNG REFLOW */
@keyframes smoothFloating {
  0%   { transform: translate3d(0, 0, 0); }
  50%  { transform: translate3d(10px, -20px, 0); }
  100% { transform: translate3d(0, 0, 0); }
}
  • ⏭️ Bước 1: Bỏ qua Layout (0ms)
  • ⏭️ Bước 2: Bỏ qua Paint (0ms)
  • 🚀 Bước 3: GPU Composite trực tiếp!
  • 🎯 Kết quả: Giữ vững 60 FPS mượt như nhung.

📜 Hướng dẫn Tích hợp Thư viện AOS

Cách thức nhúng thư viện Animate On Scroll vào bất kỳ dự án web nào chỉ với 2 bước nhanh chóng.

Bước 1: Nhúng CDN Thêm file CSS tại <head> và file JS trước thẻ đóng </body>
Bước 2: Gắn data-aos Thêm thuộc tính data-aos="fade-up" vào các thẻ HTML cần tạo hoạt ảnh
Bước 3: Khởi tạo JS Gọi hàm AOS.init({ duration: 800, once: false });
