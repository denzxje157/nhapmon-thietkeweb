Kỹ năng & Công nghệ Lập trình Game

Bộ công cụ và kiến thức tôi tích lũy qua các môn học trên giảng đường, dự án game cá nhân và các kỳ Game Jam.

1. Game Engines & Frameworks

  • Unity 2D/3D (C# Scripting, Rigidbody Physics, UI Toolkit, Tilemap)
  • Godot Engine 4 (GDScript, Kiến trúc Scene & Node, Signals)
  • Phaser.js & HTML5 Canvas (Lập trình game 2D trên trình duyệt web)
  • Unreal Engine 5 (Làm quen hệ thống Blueprints cơ bản)

2. Ngôn ngữ & Nền tảng Thuật toán

  • C / C++ (Cấu trúc dữ liệu nâng cao, giải thuật tối ưu & lập trình thi đấu)
  • C# (.NET, Lập trình hướng đối tượng OOP, Design Patterns trong Game)
  • Python (Xử lý dữ liệu, viết kịch bản script tự động hóa)
  • Toán học ứng dụng: Đại số tuyến tính, Hệ trục tọa độ, Vector, Thuật toán A*

3. Công cụ & Thiết kế Game

  • Git / GitHub (Quản lý phiên bản mã nguồn khi làm việc nhóm Game Jam)
  • Aseprite (Vẽ đồ họa Pixel Art, thiết kế Sprite Sheet & Animation 2D)
  • Blender (Dựng hình 3D phong cách Low-poly cơ bản)
  • Nền tảng phân phối itch.io (Đóng gói và phát hành game thử nghiệm)

Dự án Game tiêu biểu

Những tựa game do tôi trực tiếp lên ý tưởng thiết kế cơ chế gameplay và lập trình hoàn thiện

[Giải Nhì Game Jam]

Shadow Runner: Dimensional Shift

Tựa game 2D Puzzle-Platformer được tạo ra trong 48 giờ tại Vietnam Game Jam. Người chơi có năng lực chuyển đổi tức thời giữa hai chiều không gian "Ánh sáng" và "Bóng tối" để giải mã câu đố hóc búa, kích hoạt cơ quan bí mật và vượt chướng ngại vật.

Công nghệ sử dụng:
  • Unity Engine
  • Ngôn ngữ C#
  • 2D Rigidbody Physics
  • Aseprite Pixel Art
Chơi trên itch.io → Mã nguồn GitHub →
[Đồ án Môn học Điểm A+]

CyberSiege: Top-Down Tactical Shooter

Game hành động chiến thuật góc nhìn từ trên xuống (Top-down Shooter). Ứng dụng thuật toán tìm đường A* cho AI đối thủ, hỗ trợ đa dạng vũ khí và tích hợp hệ thống State Machine điều khiển hành vi boss linh hoạt theo khoảng cách và lượng máu còn lại.

Công nghệ sử dụng:
  • Godot Engine 4
  • Ngôn ngữ GDScript
  • Thuật toán A* Pathfinding
  • Finite State Machine (FSM)
Tải Demo cài đặt → Mã nguồn GitHub →
[Web Game Trình Duyệt]

Pixel Arena: 2D Browser Multiplayer

Trò chơi đối kháng nhiều người chơi gọn nhẹ chạy mượt mà trên trình duyệt web không cần cài đặt ứng dụng. Sử dụng HTML5 Canvas để render đồ họa tốc độ 60 FPS cùng giao thức WebSocket đồng bộ trạng thái người chơi theo thời gian thực.

Công nghệ sử dụng:
  • HTML5 Canvas
  • JavaScript (ES6+)
  • Node.js
  • WebSocket / Socket.io

Cuộc thi & Giải thưởng Tiêu biểu

Những dấu ấn nổi bật từ tinh thần chiến đấu hết mình tại các kỳ Hackathon và đấu trường lập trình

  1. Vietnam Game Jam 2025 – Giải Nhì Toàn Quốc (2nd Place)

    Thời gian: Tháng 11/2025 | Vai trò: Trưởng nhóm & Lập trình Gameplay chính

    Dẫn dắt đội ngũ 4 thành viên lên ý tưởng, xây dựng đồ họa và lập trình hoàn thiện tựa game trong vòng 48 giờ liên tục theo chủ đề bí mật của ban giám khảo. Sản phẩm được đánh giá cao nhất ở hạng mục "Sáng tạo cơ chế gameplay".

  2. Hackathon Sáng tạo Công nghệ Sinh viên 2025 – Top 10 Chung cuộc

    Thời gian: Tháng 05/2025 | Đội thi sinh viên IT

    Xây dựng giải pháp Gamification (trò chơi hóa) ứng dụng học tập tương tác giúp học sinh tiếp cận kiến thức lịch sử qua các nhiệm vụ giải đố mini game dạng nhập vai.

  3. Cuộc thi Lập trình Thuật toán Sinh viên (ICPC Cấp Trường) – Giải Khuyến Khích

    Thời gian: Tháng 12/2024 | Bảng thi đấu cá nhân

    Giải quyết 6/9 bài toán thuật toán cấu trúc dữ liệu nâng cao bằng ngôn ngữ C++ trong thời gian 4 giờ thi đấu căng thẳng, củng cố nền tảng tư duy toán học cho lập trình game.
