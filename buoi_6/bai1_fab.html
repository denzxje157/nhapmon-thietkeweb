Floating Action Button (FAB)

Nút tương tác cố định ở góc màn hình kết hợp hiệu ứng rung nở (Pulse Animation) liên tục thu hút người dùng, không gây gián đoạn trải nghiệm.

Mô phỏng Giao diện & Trải nghiệm Cuộn trang

Hãy cuộn trang lên xuống: Bạn sẽ thấy nút FAB tròn màu xanh ở góc dưới bên phải màn hình luôn cố định vị trí (position: fixed) và liên tục co giãn với hiệu ứng sóng tỏa nhẹ (@keyframes pulseAnimation).

🌟 Trải nghiệm tương tác Micro-interaction

Nút FAB giúp khách hàng truy cập nhanh vào các kênh liên hệ quan trọng nhất như Zalo, Messenger hoặc Gọi trực tiếp. Hiệu ứng nhịp tim liên tục nhắc nhở người xem mà không che khuất nội dung trang web.

Khi rê chuột vào nút, chuyển động tự động tạm dừng (animation-play-state: paused) và nút hơi phóng to tạo phản hồi trực quan rõ ràng. Bấm vào nút để mở rộng danh sách kênh liên hệ!

💡 Mẹo kiểm thử: Bấm trực tiếp vào nút tròn góc dưới để mở/đóng menu mở rộng. 
/* Đoạn mã CSS Keyframes cho hiệu ứng Pulse */
@keyframes pulseAnimation {
  0% {
    transform: scale(1);
    box-shadow: 0 0 0 0 rgba(14, 165, 233, 0.7);
  }
  50% {
    transform: scale(1.08);
    box-shadow: 0 0 0 16px rgba(14, 165, 233, 0);
  }
  100% {
    transform: scale(1);
    box-shadow: 0 0 0 0 rgba(14, 165, 233, 0);
  }
}
